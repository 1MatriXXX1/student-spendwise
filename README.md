
Student SpendWise is a simple, command-line interface (CLI) application designed to help students track their daily expenses and manage their budgets efficiently.

Features
Expense Tracking: Add new expenses and categorize them (Food, Fun, Bills, etc.).
Custom Categories: Easily add new expense categories on the fly.
Budget Management: Set, check, and update your monthly budget.
Real-time Status: View your total spending and see how much you have left relative to your budget.

How to use
Run the script using Python:

python main.py

Follow the on-screen menu:
1. Add new expense: Enter the category and the cost of your purchase.
2. View expenses: Select a category to see all items bought within it.
3. Budget: Plan your budget, check your current status, or update the budget amount.
4. Exit: Close the application.

Technologies Used

Python: Core language used for logic and data handling.
Dictionaries: Used to store expenses in a structured format (category-based nesting).
Input Handling: Basic try-except blocks to prevent crashes on invalid number inputs.
Future Improvements
Adding data persistence (saving expenses to a .txt or .json file).
Visualizing spending reports using libraries like matplotlib.
